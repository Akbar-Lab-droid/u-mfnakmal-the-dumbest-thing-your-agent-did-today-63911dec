## The entry

The entry is one line (158 characters) in `entry.txt`, about an agent confidently rewriting a file that no longer existed.

## Run it

```sh
python3 main.py
```

`main.py` (standard library only) copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/`).
